# 更新日志

## v1.0.1 (2026-02-10)

### 简化坐标校准流程

**变更内容**：
- ✅ 移除仓库选择位置的标记步骤（使用默认配置）
- ✅ 移除滚动区域的标记步骤（使用默认配置）
- ✅ 简化校准工具的操作流程

**原因**：
- 仓库选择位置在不同游戏版本中位置相对固定
- 滚动区域可以使用默认的仓库网格区域
- 减少用户标记的工作量，提高易用性

**影响**：
- 校准步骤从原来的 **8个步骤** 减少到 **6个步骤**
- 标记点数从 **约50个** 减少到 **约44个**
- 校准时间预计减少 **20%**

**需要标记的位置**（更新后）：
1. 仓库网格（8列×4行，共32个点）
2. 自动存放按钮
3. 仓库切换按钮
4. 确认按钮
5. 关闭按钮
6. 8个物品分类按钮

**使用默认配置的位置**：
- 仓库选择位置（5个）
- 滚动区域（2个点）

**如何调整默认配置**：

如果默认的仓库选择位置或滚动区域不准确，可以手动编辑生成的配置文件：

```python
# 在 config/layout_1080p_generated.py 中

# 调整仓库选择位置
@property
def WAREHOUSE_SELECT_POSITIONS(self) -> dict[str, Point]:
    return {
        "仓库1": Point(960, 300),  # 修改这里的坐标
        "仓库2": Point(960, 380),
        # ...
    }

# 调整滚动区域
@property
def SCROLL_AREA(self) -> Region:
    return Region(Point(200, 200), Point(1400, 800))  # 修改这里的坐标
```

**更新的文件**：
- `examples/calibrate_coordinates.py` - 移除相关标记步骤
- `README.md` - 更新标记说明
- `QUICKSTART.md` - 更新快速开始指南
- `FILES_OVERVIEW.md` - 更新文件说明
- `config/layout_1080p.py` - 添加默认配置说明

## 升级指南

### 从 v1.0.0 升级到 v1.0.1

如果你已经使用 v1.0.0 版本标记过坐标，无需重新标记。新版本只是简化了校准流程，不影响已有配置。

如果你想重新校准坐标：
1. 删除旧的配置文件（如果有）
2. 运行新的校准工具
3. 按照新的步骤标记（少了2个步骤）

### 兼容性

- ✅ 向后兼容 v1.0.0 的配置文件
- ✅ 不需要重新安装依赖
- ✅ 不需要修改现有的转移配置
