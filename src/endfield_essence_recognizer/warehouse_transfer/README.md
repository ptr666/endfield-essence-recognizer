# 仓库物品转移功能模块

## 功能概述

本模块实现终末地游戏中不同仓库之间的物品自动转移功能。通过图像识别和自动化点击，实现从源仓库提取指定物品并转移到目标仓库的循环操作。

## 文件说明

### 1. 配置文件

#### `config/layout_1080p.py`
定义1920×1080分辨率下仓库界面的所有坐标位置，包括：
- 仓库物品网格坐标（8列×4行）
- 功能按钮坐标（自动存放、仓库切换等）
- 物品分类按钮坐标（8种分类）
- 仓库选择坐标
- 滚动区域定义

#### `config/transfer_config.py`
定义转移任务的配置参数，包括：
- 源仓库和目标仓库名称
- 要转移的物品列表
- 物品分类设置
- 转移数量和循环次数
- 延迟时间配置

### 2. 核心功能模块

#### `core/input_controller.py`
扩展的输入控制功能，提供：
- `ctrl_right_click()` - Ctrl+右键点击
- `scroll_wheel()` - 鼠标滚轮滚动
- `press_key()` - 键盘按键模拟

#### `core/item_recognizer.py`
物品识别器，基于现有的`Recognizer`类：
- 加载物品模板图像
- 在仓库网格中识别物品
- 支持模糊匹配和置信度阈值

#### `core/warehouse_scanner.py`
仓库扫描器主逻辑，实现完整的转移流程：
- 自动存放背包物品
- 选择物品分类
- 查找并点击目标物品
- Ctrl+右键转移物品
- 切换仓库
- 循环执行

### 3. 模板资源

#### `templates/items/`
存放物品图标或名称的截图模板，用于识别：
- 蓝铁矿.png
- 其他需要转移的物品

#### `templates/ui/`
存放UI按钮的截图模板，用于场景检测：
- 自动存放按钮.png
- 仓库切换按钮.png
- 确认按钮.png

#### `templates/categories/`
存放物品分类标签的截图模板：
- 矿物.png
- 材料.png
- 等其他分类

### 4. 示例脚本

#### `examples/run_transfer.py`
运行转移任务的示例脚本，展示如何：
- 初始化各个组件
- 配置转移参数
- 启动和停止扫描器

#### `examples/calibrate_coordinates.py`
坐标校准工具，帮助用户：
- 截取游戏界面
- 标记关键位置
- 生成坐标配置

## 配置步骤

### 第一步：准备模板图像

1. **启动游戏并进入仓库界面**
   - 将游戏分辨率设置为 1920×1080
   - 打开仓库界面

2. **截取物品图标**
   - 找到"蓝铁矿"物品
   - 使用截图工具截取物品图标或名称区域
   - 保存为 `templates/items/蓝铁矿.png`
   - 建议尺寸：60×60像素左右

3. **截取UI按钮**
   - 截取"自动存放"按钮：`templates/ui/自动存放按钮.png`
   - 截取"仓库切换"按钮：`templates/ui/仓库切换按钮.png`
   - 截取"确认"按钮：`templates/ui/确认按钮.png`
   - 建议尺寸：根据实际按钮大小

4. **截取分类标签**
   - 截取"矿物"分类标签：`templates/categories/矿物.png`
   - 截取其他需要的分类标签
   - 建议尺寸：根据实际标签大小

### 第二步：校准坐标

1. **运行坐标校准工具**
   ```bash
   uv run python -m endfield_essence_recognizer.warehouse_transfer.examples.calibrate_coordinates
   ```

2. **标记关键位置**
   - 工具会显示游戏窗口截图
   - 依次点击标记以下位置：
     - 仓库网格的8列×4行的每个格子中心
     - 自动存放按钮
     - 仓库切换按钮
     - 确认按钮
     - 关闭按钮
     - 8个物品分类按钮
   - **注意**：仓库选择位置和滚动区域使用默认配置，无需标记

3. **生成配置文件**
   - 工具会自动生成坐标配置
   - 保存到 `config/layout_1080p.py`

### 第三步：配置转移任务

编辑 `config/transfer_config.py`：

```python
# 源仓库和目标仓库
SOURCE_WAREHOUSE = "仓库A"
TARGET_WAREHOUSE = "仓库B"

# 要转移的物品
TRANSFER_ITEMS = [
    {
        "name": "蓝铁矿",
        "category": "矿物",
        "count": -1,  # -1表示全部转移
    }
]

# 延迟时间配置（秒）
DELAYS = {
    "after_click": 0.3,
    "after_store": 0.5,
    "after_switch": 0.5,
    "loop_interval": 1.0,
}
```

### 第四步：运行转移任务

```bash
uv run python -m endfield_essence_recognizer.warehouse_transfer.examples.run_transfer
```

按 `Ctrl+C` 停止转移。

## 注意事项

1. **分辨率要求**
   - 必须使用 1920×1080 分辨率
   - 如需其他分辨率，需重新校准坐标

2. **游戏界面要求**
   - 游戏窗口必须在前台
   - 仓库界面必须完全可见
   - 不要在运行时移动或调整窗口

3. **安全性**
   - 建议先在测试环境运行
   - 确认坐标准确后再正式使用
   - 随时准备按 Ctrl+C 停止

4. **性能优化**
   - 可以调整延迟时间以提高速度
   - 但过短的延迟可能导致操作失败

5. **错误处理**
   - 如果识别失败，会记录日志并跳过
   - 如果连续失败多次，会自动停止

## 故障排查

### 问题1：无法识别物品
- 检查模板图像是否清晰
- 检查识别阈值是否过高
- 尝试重新截取模板

### 问题2：点击位置不准确
- 重新运行坐标校准工具
- 检查游戏分辨率是否正确
- 检查窗口是否最大化

### 问题3：转移失败
- 检查背包是否已满
- 检查仓库是否已满
- 检查物品是否被锁定

### 问题4：程序卡住
- 检查游戏是否弹出对话框
- 检查网络连接是否正常
- 按 Ctrl+C 强制停止

## 扩展功能

### 添加新物品
1. 截取新物品的模板图像
2. 保存到 `templates/items/`
3. 在 `transfer_config.py` 中添加配置

### 支持多个物品
在 `TRANSFER_ITEMS` 中添加多个物品配置，扫描器会依次处理。

### 自定义转移逻辑
修改 `core/warehouse_scanner.py` 中的 `run()` 方法，实现自定义流程。
